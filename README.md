# Система денежных переводов 

Мини-система переводов между пользователями на Go. Демонстрирует
структуры и методы, работу с очередью транзакций, каналы, горутины,
`sync.WaitGroup` и защиту баланса от гонок данных через мьютекс.

## Что умеет

- Создавать пользователей с балансом.
- Пополнять баланс (`Deposit`) и снимать деньги (`WithDraw`)
  с проверкой: баланс в минус не уходит.
- Ставить переводы в очередь и обрабатывать их.
- Обрабатывать транзакции параллельно фиксированным числом воркеров
  через канал — без запуска горутины на каждую транзакцию.
- Безопасно менять баланс из нескольких горутин.

## Как запустить

```bash
go run .
```

Проверка на гонки данных:

```bash
go run -race .
```

Ожидаемый вывод:

```
Создаю UserID: 1 с балансом 1000
Создаю UserID: 2 с балансом 500
Перевожу с UserID: 1 на UserID: 2 сумму в размере 200
Перевожу с UserID: 2 на UserID: 1 сумму в размере 50
Итого
У первого пользователя должно получиться 850, а получилось 850.000000
У второго пользователя должно получиться 650, а получилось 650.000000
```

## Основные сущности

| Сущность | Назначение |
|---|---|
| `User` | Пользователь: `ID`, `Name`, `Balance`, мьютекс для защиты баланса |
| `Transaction` | Перевод: `FromID`, `ToID`, `Amount` |
| `PaymentSystem` | Контейнер: `Users` (мапа) и `TransactionQueue` (слайс) |
| `Worker` | Воркер: читает из канала и обрабатывает транзакции |

## Как это работает

1. `main` создаёт `PaymentSystem`, добавляет пользователей и транзакции.
2. Создаётся буферизованный канал `ch` размером `len(TransactionQueue)`.
3. Запускаются 3 воркера: `go ps.Worker(&wg, ch)`.
4. Транзакции отправляются в канал, затем `close(ch)`.
5. Воркеры читают через `range ch`, обрабатывают каждую транзакцию
   и завершаются при закрытии канала, вызывая `wg.Done()`.
6. `wg.Wait()` дожидается всех воркеров — потом печатаются балансы.

## Что добавлено в каждой версии

| Ветка | Часть | Что добавлено |
|---|---|---|
| `v1` | Часть 1 | Структура `User`, методы `Deposit` и `WithDraw`. Создание пользователей и операции в `main`. |
| `v2` | Часть 2 | Структуры `Transaction` и `PaymentSystem`, методы `AddUser`, `AddTransaction`, `ProcessingTransactions`. Обработка очереди по порядку. |
| `v3` | Часть 3 | Канал `chan Transaction`, метод `Worker`, 3 воркера-горутины, `sync.WaitGroup`, `close(ch)` + `wg.Wait()`. |
| `v4` | Часть 4 | `sync.Mutex` в `User`, защита `Deposit` и `WithDraw` от гонок данных. `go run -race .` проходит чисто. |

Переключение между версиями:

```bash
git checkout v1   # или v2 / v3 / v4
```
